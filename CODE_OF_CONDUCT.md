# Code of Conduct

## Our Commitment

Mintforge UI, an open-source project developed by **NEXYOUTH**, is committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in our community.

We welcome contributions from people of all experience levels, backgrounds, identities, and skill sets.

## Expected Behavior

All contributors, maintainers, and community members are expected to:

* Be respectful, professional, and considerate.
* Welcome constructive feedback and different perspectives.
* Communicate clearly and respectfully.
* Focus on what is best for the project and its community.
* Accept responsibility for mistakes and learn from them.
* Help create a positive environment for collaboration.
* Respect the time, effort, and contributions of others.

## Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment, discrimination, or personal attacks.
* Insulting, threatening, or abusive language.
* Trolling, deliberate intimidation, or disruptive behavior.
* Publishing private information without permission.
* Unwelcome sexual attention or inappropriate conduct.
* Deliberately disrupting discussions or contributions.
* Any other behavior that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub issues and pull requests.
* Discussions and code reviews.
* Project-related communication channels.
* Other spaces where someone represents Mintforge UI or NEXYOUTH in an official capacity.

## Reporting Issues

If you experience or witness unacceptable behavior, report it to the project maintainers through an appropriate private communication channel.

Please do not report sensitive incidents publicly if doing so could expose personal or confidential information.

Reports will be reviewed with care and handled as confidentially as reasonably possible.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Depending on the severity and circumstances, maintainers may take appropriate action, including:

* Issuing a warning.
* Removing inappropriate content.
* Temporarily restricting participation.
* Removing a contributor from project spaces.
* Taking other reasonable action to protect the community.

Maintainers will consider the nature and impact of each incident when determining an appropriate response.

## Our Responsibility

We aim to address reported concerns fairly, consistently, and respectfully.

Community members are encouraged to help maintain a constructive environment and raise concerns when behavior does not align with these standards.

## Acknowledgment

By participating in Mintforge UI, you agree to follow this Code of Conduct and help maintain a respectful, inclusive, and collaborative open-source community.

Thank you for helping make Mintforge UI a better place to build and contribute.
