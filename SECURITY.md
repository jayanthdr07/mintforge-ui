# Security Policy

## Supported Versions

Mintforge UI is an open-source UI ecosystem developed by **NEXYOUTH**.

Security fixes will be prioritized for actively maintained versions of the project. As the project evolves, supported versions and security update policies may be updated.

## Reporting a Vulnerability

We take security reports seriously and appreciate the efforts of developers who help keep Mintforge UI and its users safe.

If you discover a potential security vulnerability, please report it privately to the project maintainers.

**Please do not disclose security vulnerabilities through public GitHub issues, discussions, or pull requests.**

When submitting a report, include the following details whenever possible:

* A clear description of the potential vulnerability.
* The affected component, package, or version.
* Steps to reproduce the issue.
* The potential impact.
* Relevant logs, screenshots, or proof-of-concept details that do not expose real user data.

## Reporting Channel

Until a dedicated security reporting channel is established, use GitHub's **private vulnerability reporting** feature if it is enabled for the repository.

You can find this option in the repository's **Security** tab under **Report a vulnerability**.

If private vulnerability reporting is unavailable, contact the project maintainers through an appropriate private channel before sharing sensitive technical details.

## What to Expect

After receiving a report, the maintainers will aim to:

1. Review the report and assess its validity and impact.
2. Communicate with the reporter when additional information is needed.
3. Work on an appropriate fix or mitigation.
4. Coordinate disclosure after the issue has been addressed, where practical.

Response and resolution times may vary depending on the severity and complexity of the issue and the availability of maintainers.

## Responsible Disclosure

Please give the maintainers a reasonable opportunity to investigate and address a reported vulnerability before publicly disclosing it.

Do not access, modify, or expose data that does not belong to you, and do not perform testing that could disrupt services or affect other users.

## Scope

Security reports may include issues involving:

* UI components and reusable blocks.
* Installation tools and project packages.
* Documentation website functionality.
* Dependencies and configuration that introduce security risks.
* Other project-maintained code that could affect users' security.

## Thank You

We appreciate responsible security research and the community members who help make Mintforge UI safer for everyone.
